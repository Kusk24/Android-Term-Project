# Motopedia

## Description
Motopedia is a platform designed like Wikipedia, focusing on motorcycle-related topics. It provides in-depth details about motorcycles, brands, history, technology, and more. The platform aims to be an intuitive and informative resource for motorcycle enthusiasts, offering easy access to a wealth of knowledge.

## Features
- Search motorcycles by brand and model
- Explore brands and their store locations
- Upload and contribute articles about motorcycles
- Admin review system for submitted content (approve or reject based on quality and accuracy)

## Setup
1. Clone the repo from GitHub
2. Add `google-services.json` in your app/ directory ('Android-Term-Project/app/google-services.json')
3. In `local.properties`, add your Google Maps API key:
   GOOGLE_MAPS_API_KEY=YOUR_GOOGLE_MAPS_API_KEY
4. Build and run in Android Studio
5. Enjoy exploring and contributing!
